# 更新日誌 {#top}

## 2.3 — 目錄整理、巢狀分組與發佈準備 {#v2-3}

- **目錄整理**：按分組把 plugins 整理成對應的資料夾，**只移動、不改模組資料夾名**，先看預覽樹再執行；空資料夾可放進回收站；完成後彈窗告訴你結果。
- **分組**：分組可以巢狀三層，右鍵標題新增子分組，拖動標題掛到別的分組下；首次進入時可按現有分類資料夾一鍵生成分組。分組摺疊不再整頁重新整理。
- **識別更全**：資源包（沒有 DLL 的包）、散放在 plugins 根目錄的 DLL、任意字尾的停用檔案、巢狀在別的模組資料夾裡的模組都能識別並標出。
- **基礎組件**：可以改譯名、啟停、解除安裝（解除安裝前額外提醒）。
- **保護白名單**：只有管理器和它執行所需的 ModConfig、PEAKLib.Core、PEAKLib.UI 不能停用或解除安裝，其餘全部放開；啟停不彈確認，解除安裝先確認。
- **角標**：七種狀態角標顏色各不相同、位置固定、懸停有說明；名稱欄加寬。
- **翻譯**：全部介面文字都有英文原文和簡繁中文，並進入翻譯匯出。不再需要 XUnity AutoTranslator：模組設定頁的選項名、分區和下拉選項由管理器自己的語言檔案翻譯，語言檔案支援 `r:` 正則規則；「匯入補翻」把填好的匯出檔案合進語言檔案；XUnity 開著線上機翻時會提醒。個人資料資料夾整理成 language、profiles、output、data 四個，見「翻譯模組 › 檔案放在哪」。
- **使用說明**：重寫，加入三分鐘上手、介面圖例和術語表。
- **效能**：首次進入概覽不再重複構建列表。
- **適配遊戲 3.1**：模組參數的小數恢復正常顯示（遊戲新版會把它們顯示成整數，輸入時還會存錯值）；設定格子裡「儲存」與「預設」橫著並排，下拉框和文字框一樣高。全部介面統一為藍色主題，並新增紫色主題，可手動切換或夜裡自動切換（不再讀取 TimeTheme 的配色）；置頂豎線改細、改用青檸色；子分組色條逐級變細變短。按鈕恢復按功能分色系（兩套主題各一組），使用說明單獨一種顏色；快捷鍵頁模組名前加上與概覽一致的序號。修復匯出日誌時遊戲直接當機。同一個套件留有多份版本不同的說明檔案時，不再反覆提醒已經裝好的更新。改名為「遊戲內模組管理器」（In-Game Mod Manager），已有的方案和設定不受影響。設定頁左欄加寬，「搜尋」標題和搜尋框收小、不再互相遮擋，工具列文字放不下時自動縮小，分組列比模組列更醒目。

## 2.2 — 新的更新核心 {#v2-2}

- **更新助手重寫**：以本機檔案為基準，依賴自動入隊；新裝模組不用等退出遊戲，只有替換已載入的 DLL 時才等；同時進行的任務互不阻塞。
- **獨立執行**：安裝、更新、解除安裝點了就入隊，不再經過「儲存設定」。
- **前臺視窗**：助手只在有任務時出現，等待退出時最小化，不在後臺駐留。
- **更新記錄**：按批次分組，顯示下載速度和用時；已經結束的記錄不會在每次啟動時重複提示。
- **管理器檔案**：支援 r2modman、雷霆管理器的檔案佈局，所有功能可用，並同步管理器的版本記錄。
- **重複副本**：同一模組裝了多份時可以獨立勾選，勾選一份自動停用其他副本。
- **介面效能**：概覽分幀開啟、重新整理分攤到多幀，減少卡頓。

## 2.1 — 統一儲存與環境管理 {#v2-1}

- **配置**：參數、快捷鍵、啟停統一草稿，儲存即提交，區域性儲存隔離範圍；保留作者原版與恢復草稿。
- **資源**：安裝、匯入、更新、解除安裝由助手核驗與執行（2.2 起改為直接入隊，不再進草稿）。
- **瀏覽**：即時多欄位搜尋、狀態優先篩選，相關模組跳轉包含依賴提供者。
- **檢查**：重複插件按自身 DLL 對比；依賴問題與來源未識別分別提示，提供重識別和手動確認。
- **閱讀**：主頁顯示商店與 GitHub 連結，功能介紹按目前流程校對；隱藏列表減少空轉，效能診斷移交 FrameDoctor。

## 2.0.0 — 遊戲內整合包管理 {#v2-0-0}

自商店公開版 1.0.2 以來最大的一次更新，中間的本機開發版本統一合併為本次公開更新。

### 面向普通使用者

- 新增獨立整合包庫、統一 ZIP／目錄匯入、固定版本遞迴依賴，以及每包獨立的個人方案。
- 接管與切換先預覽確認，退出後儲存最終配置和更新後的模組檔案，保護本機宿主，失敗恢復舊環境。
- 新增原生模組概覽，按彩色分組瀏覽，檢視完整版本、作者、來源和依賴，快捷開啟設定、主頁及目錄。
- 設定方案統一記錄參數、快捷鍵、模組啟用目標、分組和介紹；作者預設保持只讀，玩家可建立個人副本。
- 明確區分“僅儲存”“應用配置”，按分類、分組和模組顯示原值、目標及生效說明，直接檢視實際載入、待應用與待重新啟動狀態。
- 整合包衝突建議適用於所有方案，淺黃色角標和應用前分類提示展示原因；本機忽略後保留詳情。
- 快捷鍵按分組和模組排列，對照目前按鍵、模組預設與方案預設，提供重複及未繫結檢查。
- 直接從雷霆商店下載，使用獨立更新佇列、版本選擇和回退歷史，顯示進度、成功／失敗及退出／重新啟動狀態。
- 提供系統代理、直連、自定義 HTTP(S) 代理，分別測試商店和下載連線。
- 內建英文、簡體中文和繁體中文，支援附加語言詞典、翻譯匯出／過載及 XUnity 聯動。
- 保留並整合樹形設定側欄、說明面板、搜尋、篩選、置頂、控制器導航和可選 TimeTheme 配色。

### 面向整合包作者

- 管理中心統一提供整合包／模組資料、分組、方案、更新、網路、工具、發佈和預覽。
- 遊戲內介紹編輯器支援文字排版、連結、圖片、GIF、影片、字型、媒體佈局及 Markdown 匯入／匯出。
- 作者可設兩項或多項模組衝突，選擇任意兩項／全部啟用觸發；草稿獨立儲存，隨包匯出並簽名。
- 可提供多套推薦方案、指定發佈包預設方案、附帶作者詞典和來源記錄，併為作者資料選擇簽名。
- 支援僅作者資料、完整本機整合包和雷霆商店格式匯出，明確選擇配置、附件，使用易識別的整合包名稱。
- 分類檔案預覽提供目錄樹、文本／Markdown／媒體檢視，以及面向本次匯出的文本和配置編輯。
- 本機匯出的目標目錄只保留一個 ZIP；發佈草稿和目前方案介紹分別儲存，操作後說明作用範圍。
- 發行壓縮包按安裝目錄保留執行庫、Windows x64 更新助手、示例和許可證檔案。

### 升級說明

替換舊版前先退出 PEAK，保留 `BepInEx/config/ModConfigEnhance/` 中的個人資料。原有語言與概覽資料會遷移；準備好後選擇並應用方案，涉及模組啟停時重新啟動遊戲。
