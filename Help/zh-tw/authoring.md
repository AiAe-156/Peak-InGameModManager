## 準備方案和介紹 {#prepare}

在管理方案中新增或複製設定預設，記錄要發布的參數、快捷鍵及啟停目標。預設名稱與整合包名稱獨立；資料、介紹、分組及媒體屬於整合包工作區。作者預設在本機沿用身分編輯，首次儲存選擇原地或另存。切到編輯模式填寫名稱、版本、作者、日期及介紹標題，並儲存對應資料。
開啟「顯示整合包介紹」，準備有效正文後即可顯示介紹頁。頁籤標題留空時使用預設名稱。介紹建議包含玩法特點、安裝要求、常用操作與更新說明，先讓玩家知道怎樣開始。

## 文字與 Markdown {#markdown}

在介紹頁進入編輯，像文字處理軟件一樣輸入。回車新建段落，Shift+回車在段內換行；拖動選擇文字，再用工具欄調整標題、清單、引用、字號、顏色、背景和對齊。

連結工具用於設定網址；閱讀時點選打開，編輯時用 Ctrl+單擊。Ctrl+Z/Y 撤銷或重做，Ctrl+S 儲存。段首輸入標題、清單或引用標記可轉換樣式。

「更多」提供 Markdown 原始碼、匯入／另存 Markdown 和載入示範稿。MCE Markdown 帶有儲存文字格式和媒體排版的擴展，使用現有編輯器生成的內容最方便。示範稿載入後可先預覽，確認並儲存後採用。

## 圖片、動畫和影片 {#media}

用「插入」選擇圖片、GIF 或影片。單擊媒體選中，拖四角改變大小；浮動工具列可設對齊、尺寸、說明和替換。拖左側六點手把可移動位置，拖到另一媒體左右側可組成並排。

支援 PNG/JPEG、GIF，以及現有 MP4/WEBM/MOV/AVI/M4V/OGV 影片播放；影片需要系統支援對應解碼。用媒體下方控件播放、暫停、調進度與音量。字型可從整合包工作區字型目錄選擇 TTF/OTF/TTC，發佈前確認允許分發。

## 儲存與發佈準備 {#save}

正文儲存為 MCE 文檔，並同時輸出相容 Markdown。介紹與引用素材儲存在整合包共用工作區；匯入尚未完成時，等完成後再儲存或切換方案。

發佈前以閱讀模式檢查文字、連結、圖片和影片，再儲存方案，核對預設設定及[模組來源](sources#types)。匯出會收集共用介紹引用的媒體和字型，接著在[發佈向導](export#steps)選擇語言、檔案和簽名。

## 編輯 MCE 使用說明 {#guide-edit}

在 MCE 設定「5. 文件編輯」開啟「允許編輯功能說明」，預設關閉。全部說明章節及更新日誌會使用與介紹頁相同的編輯工具列，支援格式、連結、圖片、影片、字型與 Markdown 原始碼。

修改依語言寫入 `config/ModConfigEnhance/data/help/<語言>/`，獨立於設定方案。切換章節或返回前請儲存；未儲存時可選擇儲存、放棄或繼續編輯。關閉編輯開關後仍顯示已儲存修改。「還原本頁內建內容」只還原目前語言的目前章節，原覆寫資料移入備份。

編輯器「更多 → 匯出說明資料」會匯出三語正文、編輯文件與素材。匯出的 `Help/` 可放回 MCE 專案製作下一版：正文隨 DLL 內建，圖片／影片／字型隨 MCE 插件分發。標題錨點在編輯與匯出後保留，修改標題文字後仍可跳轉。編輯開關由本機決定，不會由整合包預設設定自動開啟。

## 整合包衝突預設 {#conflicts}

作者模式下進入 **管理中心 → 發布 → 整合包衝突預設**。新增規則，選擇至少兩個可獨立啟停的模組包，填寫衝突原因。同包模組視為一個啟停單元；已記錄但本機缺少的成員繼續保留。

**任意兩項同時啟用**：A+B、A+C、B+C 或全部啟用都會提醒。**全部同時啟用**：僅 A+B+C 全部啟用時提醒。規則僅作建議，玩家仍可繼續套用。草稿按整合包獨立儲存，關閉管理中心後保留；匯出時透過 `MCEPack/conflicts.json` 分發給所有方案，並納入作者資料簽章。個人方案匯出及玩家本機忽略資料各自獨立。
