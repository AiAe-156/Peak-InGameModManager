# 如何打包 {#top}

先准备一套可以游玩的方案，再整理整合包信息与介绍，最后进入发布向导。本页主要讲介绍制作和发布前准备；生成文件的步骤见[导出与发布](export)。 · [编辑使用说明](#guide-edit)

本页目录：[准备方案和介绍](#prepare) · [文字与 Markdown](#markdown) · [图片、动画和视频](#media) · [保存与发布准备](#save)

## 准备方案和介绍 {#prepare}

在管理方案中新建或复制配置预设，记录希望发布的参数、快捷键和启停目标。预设名与整合包名独立；资料、介绍、分组和媒体属于整合包工作区。作者预设在本机沿用身份编辑，首次保存选择原地或另存。切到编辑模式填写名称、版本、作者、日期及介绍标题，并保存对应资料。
开启「显示整合包介绍」，准备有效正文后即可显示介绍页。页签标题留空时使用默认名称。介绍建议包含玩法特点、安装要求、常用操作与更新说明，先让玩家知道怎样开始。

## 文字与 Markdown {#markdown}

在介绍页进入编辑，像文字处理软件一样输入。回车新建段落，Shift+回车在段内换行；拖动选择文字，再用工具栏调整标题、列表、引用、字号、颜色、背景和对齐。

链接工具用于设置网址；阅读时点击打开，编辑时用 Ctrl+单击。Ctrl+Z/Y 撤销或重做，Ctrl+S 保存。段首输入标题、列表或引用标记可转换样式。

「更多」提供 Markdown 源码、导入／另存 Markdown 和载入示范稿。管理器的 Markdown 带有保存文字格式和媒体排版的扩展，使用现有编辑器生成的内容最方便。示范稿载入后可先预览，确认并保存后采用。

## 图片、动画和视频 {#media}

用「插入」选择图片、GIF 或视频。单击媒体选中，拖四角改变大小；浮动工具条可设对齐、尺寸、说明和替换。拖左侧六点手柄可移动位置，拖到另一媒体左右侧可组成并排。

支持 PNG/JPEG、GIF，以及现有 MP4/WEBM/MOV/AVI/M4V/OGV 视频播放；视频需要系统支持对应解码。用媒体下方控件播放、暂停、调进度与音量。字体可从整合包工作区字体目录选择 TTF/OTF/TTC，发布前确认允许分发。

## 保存与发布准备 {#save}

正文保存为管理器文档，并同时输出兼容 Markdown。介绍与引用素材保存在整合包共用工作区；导入尚未完成时，等完成后再保存或切换方案。

发布前以阅读模式检查文字、链接、图片和视频，再保存方案，核对默认配置及[模组来源](sources#types)。导出会收集共用介绍引用的媒体和字体，接着在[发布向导](export#steps)选择语言、文件和签名。

## 编辑使用说明 {#guide-edit}

在管理器设置“5. 文档编辑”中开启“允许编辑功能说明”，默认关闭。全部说明章节及更新日志会使用与介绍页相同的编辑工具栏，支持格式、链接、图片、视频、字体与 Markdown 源码。

修改按语言写入 `config/InGameModManager/data/help/<语言>/`，独立于配置方案。切章节或返回前保存；未保存时可以选择保存、放弃或继续编辑。关闭编辑后仍显示已保存修改。“恢复本页内置”只恢复当前语言的当前章节，原覆盖资料移入备份。

编辑器“更多 → 导出说明资料”会导出三语正文、编辑文档与素材。导出的 `Help/` 可放回管理器工程制作下一版：正文随 DLL 内置，图片／视频／字体随管理器插件分发。标题锚点在编辑与导出后保留，修改标题文字后仍可跳转。编辑开关由本机决定，不由整合包默认设置自动开启。

## 整合包冲突预设 {#conflicts}

作者模式下进入 **管理中心 → 发布 → 整合包冲突预设**。新建规则，选择至少两个能独立启停的模组包，并填写冲突原因。同包模组按一个启停单元选择；已记录但本机缺失的成员继续保留。

**任意两项同时启用**：A+B、A+C、B+C 或三项全部启用都会提醒。**全部同时启用**：只在 A+B+C 全部启用时提醒。规则只作建议，玩家始终可以继续应用。规则草稿按整合包独立保存，关闭管理中心后仍保留；导出时通过 `IGMMPack/conflicts.json` 分发给所有方案，并纳入作者资料签名。个人方案导出和玩家本机忽略记录各自独立。
