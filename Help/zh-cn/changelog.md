# 更新日志 {#top}

## 2.3 — 目录整理、嵌套分组与发布准备 {#v2-3}

- **目录整理**：按分组把 plugins 整理成对应的文件夹，**只移动、不改模组文件夹名**，先看预览树再执行；空文件夹可放进回收站；完成后弹窗告诉你结果。
- **分组**：分组可以嵌套三层，右键标题新建子分组，拖动标题挂到别的分组下；首次进入时可按现有分类文件夹一键生成分组。分组折叠不再整页刷新。
- **识别更全**：资源包（没有 DLL 的包）、散放在 plugins 根目录的 DLL、任意后缀的停用文件、嵌套在别的模组文件夹里的模组都能识别并标出。
- **基础组件**：可以改译名、启停、卸载（卸载前额外提醒）。
- **保护白名单**：只有 MCE 和它运行所需的 ModConfig、PEAKLib.Core、PEAKLib.UI 不能停用或卸载，其余全部放开；启停不弹确认，卸载先确认。
- **角标**：七种状态角标颜色各不相同、位置固定、悬停有说明；名称列加宽。
- **翻译**：全部界面文字都有英文原文和简繁中文，并进入翻译导出。不再需要 XUnity AutoTranslator：模组设置页的选项名、分区和下拉选项由管理器自己的语言文件翻译，语言文件支持 `r:` 正则规则；「导入补翻」把填好的导出文件合进语言文件；XUnity 开着在线机翻时会提醒。个人数据文件夹整理成 language、profiles、output、data 四个，见「翻译模块 › 文件放在哪」。
- **使用说明**：重写，加入三分钟上手、界面图例和术语表。
- **性能**：首次进入概览不再重复构建列表。
- **适配游戏 3.1**：模组参数的小数恢复正常显示（游戏新版会把它们显示成整数，输入时还会存错值）；设置格子里「保存」与「默认」横着并排，下拉框和文本框一样高。全部界面统一为蓝色主题，并新增紫色主题，可手动切换或夜里自动切换（不再读取 TimeTheme 的配色）；置顶竖线改细、改用青柠色；子分组色条逐级变细变短。按钮恢复按功能分色系（两套主题各一组），使用说明单独一种颜色；快捷键页模组名前加上与概览一致的序号。修复导出日志时游戏直接崩溃。同一个包留有多份版本不同的说明文件时，不再反复提醒已经装好的更新。改名为「游戏内模组管理器」（In-Game Mod Manager），已有的方案和设置不受影响。设置页左栏加宽，「搜索」标题和搜索框收小、不再互相遮挡，工具行文字放不下时自动缩小，分组行比模组行更醒目。

## 2.2 — 新的更新核心 {#v2-2}

- **更新助手重写**：以本地文件为基准，依赖自动入队；新装模组不用等退出游戏，只有替换已加载的 DLL 时才等；同时进行的任务互不阻塞。
- **独立执行**：安装、更新、卸载点了就入队，不再经过「保存配置」。
- **前台窗口**：助手只在有任务时出现，等待退出时最小化，不在后台驻留。
- **更新记录**：按批次分组，显示下载速度和用时；已经结束的记录不会在每次启动时重复提示。
- **管理器档案**：支持 r2modman、雷霆管理器的档案布局，所有功能可用，并同步管理器的版本记录。
- **重复副本**：同一模组装了多份时可以独立勾选，勾选一份自动停用其他副本。
- **界面性能**：概览分帧打开、刷新分摊到多帧，减少卡顿。

## 2.1 — 统一保存与环境管理 {#v2-1}

- **配置**：参数、快捷键、启停统一草稿，保存即提交，局部保存隔离范围；保留作者原版与恢复草稿。
- **资源**：安装、导入、更新、卸载由助手核验与执行（2.2 起改为直接入队，不再进草稿）。
- **浏览**：即时多字段搜索、状态优先筛选，相关模组跳转包含依赖提供者。
- **检查**：重复插件按自身 DLL 对比；依赖问题与来源未识别分别提示，提供重识别和手动确认。
- **阅读**：主页显示商店与 GitHub 链接，功能介绍按当前流程校对；隐藏列表减少空转，性能诊断移交 FrameDoctor。

## 2.0.0 — 游戏内整合包管理 {#v2-0-0}

自商店公开版 1.0.2 以来最大的一次更新，中间的本地开发版本统一合并为本次公开更新。

### 面向普通用户

- 新增独立整合包库、统一 ZIP／目录导入、固定版本递归依赖，以及每包独立的个人方案。
- 接管与切换先预览确认，退出后保存最终配置和更新后的模组文件，保护本机宿主，失败恢复旧环境。
- 新增原生模组概览，按彩色分组浏览，查看完整版本、作者、来源和依赖，快捷打开设置、主页及目录。
- 配置方案统一记录参数、快捷键、模组启用目标、分组和介绍；作者预设保持只读，玩家可建立个人副本。
- 明确区分“仅保存”“应用配置”，按分类、分组和模组显示原值、目标及生效说明，直接查看实际加载、待应用与待重启状态。
- 整合包冲突建议适用于所有方案，浅黄色角标和应用前分类提示展示原因；本机忽略后保留详情。
- 快捷键按分组和模组排列，对照当前按键、模组默认与方案预设，提供重复及未绑定检查。
- 直接从雷霆商店下载，使用独立更新队列、版本选择和回退历史，显示进度、成功／失败及退出／重启状态。
- 提供系统代理、直连、自定义 HTTP(S) 代理，分别测试商店和下载连接。
- 内置英文、简体中文和繁体中文，支持附加语言词典、翻译导出／重载及 XUnity 联动。
- 保留并整合树形设置侧栏、说明面板、搜索、筛选、置顶、手柄导航和可选 TimeTheme 配色。

### 面向整合包作者

- 管理中心统一提供整合包／模组资料、分组、方案、更新、网络、工具、发布和预览。
- 游戏内介绍编辑器支持文字排版、链接、图片、GIF、视频、字体、媒体布局及 Markdown 导入／导出。
- 作者可设两项或多项模组冲突，选择任意两项／全部启用触发；草稿独立保存，随包导出并签名。
- 可提供多套推荐方案、指定发布包默认方案、附带作者词典和来源记录，并为作者资料选择签名。
- 支持仅作者资料、完整本地整合包和雷霆商店格式导出，明确选择配置、附件，使用易识别的整合包名称。
- 分类文件预览提供目录树、文本／Markdown／媒体查看，以及面向本次导出的文本和配置编辑。
- 本地导出的目标目录只保留一个 ZIP；发布草稿和当前方案介绍分别保存，操作后说明作用范围。
- 发行压缩包按安装目录保留运行库、Windows x64 更新助手、示例和许可证文件。

### 升级说明

替换 MCE 前先退出 PEAK，保留 `BepInEx/config/ModConfigEnhance/` 中的个人数据。原有语言与概览数据会迁移；准备好后选择并应用方案，涉及模组启停时重启游戏。
