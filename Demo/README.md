# Introduction demo

Open the modpack introduction editor and choose Load demo draft from its tools. Store the draft to use it as the current introduction; referenced media is copied into the profile resources.

The example includes group descriptions, formatted text, links, images, GIFs and an existing video. The `profile-format` folder shows the author profile format; replace example identities and values before distributing it.

# 整合包介绍示范稿

在整合包介绍编辑器的工具中选择“载入示范稿”，存储后用作当前介绍，引用的媒体会复制到方案资源目录。

示例包含分组说明、文字排版、链接、图片、GIF 和现有视频。`profile-format` 文件夹展示作者方案格式；分发前请替换示例身份和参数。
