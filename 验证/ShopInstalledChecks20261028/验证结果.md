# 商店安装状态修复验证（2026-10-28，2.0.0，未部署）

## 根因与改动
- ShopWindow 原先在打开时只把传入 overview 行和 ledger key 合并成一次性集合；OpenPackage 可仅传一个模组；core/patchers 只在独立列表中扫描。有更新筛选、详情又只认 overview 行，导致同包不同入口互相矛盾。
- 旧“已安装”是底部统计末尾的普通文字，可能被截断，并非明确徽标。
- 新 `src/Overview/ShopInstalled.cs` 为显示专用生产识别函数：当前 ledger（需实际运行文件）、完整确认来源 overview/缓存插件和 core/patchers manifest 聚合。仅当前 ledger，不读取其他包库存；manifest 版本优先于旧 receipt / overview 版本。错误 manifest、无 payload、相互矛盾身份不推断安装；重复路径保留，更新筛选不把混合版本错误报为全可更新。
- ShopWindow 卡片单独绿色“已安装”，本地／商店版本分开，有更新独立一行；禁用／缓存停用区别显示。“本地安装”页显示真实路径及本次加载版本。FlatListRow 只有颜色 hover，不放大，不遮名称。
- 磁盘后台聚合每5秒刷新一次，卡片和筛选只查内存快照；切包立即清空旧快照，context + generation 丢弃过期任务（含 A→B→A），显式刷新重新读取确认来源。未引入逐卡磁盘扫描。完整 overview 只在打开、切包和用户刷新时重新获取，文件快照每5秒重新验证。
- InfrastructurePackages 共用同一 manifest 解析器；显示状态不授予写权限。core 详情禁止安装和卸载；patcher 仍走原预览策略；归属不明不因安装徽标获得卸载权限。安装事务代码未修改，不搬文件。
