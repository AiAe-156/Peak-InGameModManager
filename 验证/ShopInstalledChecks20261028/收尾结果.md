# 已安装卡片 tester 收尾结果（2026-10-28）

版本保持 **2.0.0**。只改本轮源码、隔离测试及记录；**未打包、未部署**，没有启动游戏或修改真实配置、库存、队列、其他模组、core、PEAK_Data。

## 修复

1. 快照比较由实例替换／无条件 Draw 改为 `ShopInstallationState.Signature`：证据元组序列化、去重、稳定排序，覆盖包身份、版本、路径、区域、禁用及缓存状态。相同内容的新实例、不同字典／证据顺序不会触发安装状态重绘。
2. 有变化时，列表维持当前页码（结果减少时按范围夹取）、恢复左右列表 content 位置；选中详情不调用 Draw，仅更新安装状态、安装／更新／卸载按钮及本地安装文本。介绍与更新日志阅读器不因安装徽标刷新 Dispose/Reload，不抢任务页或详情页。
3. 生产状态机明确 Reading / Ready / Failed；首次及切包清空旧就绪状态，显示“正在读取安装状态”。Reading、Failed 均禁安装／更新／卸载，并在事件入口复核；Ready 按原安装／归属条件开放，core 始终只读。
4. 任务异常、目录读取失败及 ledger 读取失败进入可见失败状态；提供“重试安装状态”，仍保留后台重试。普通 manifest 无效仍仅作为无效证据忽略，不扩展安装权限。根级扫描异常由任务完成处理捕获。旧 generation/context 的成功或错误均不应用。
