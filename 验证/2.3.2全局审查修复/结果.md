# 2.3.2 全局审查修复

问题来源：[审查结论.md](审查结论.md)（2.3.1 全局审查，9 条）。改动前快照：`备份/2.3.2_20261109_全局审查修复前/`。

## 逐条处理
| # | 问题 | 改法 |
|---|---|---|
| 1 | 自动更新检查整段在主线程（8 次 295–489 ms 卡顿） | `AutomaticUpdateChecks` 改用 `Task.Run(() => Run(...))` 启动；仓库与扫描仍在主线程预先准备 |
| 2 | 已弃用的包让检查每 60 秒重跑 | `CacheEntry.Settled` 标记确定答复（弃用/404/非 408、429 的 4xx/`InvalidDataException`）；`CheckProgress.TransientFailed`；`RetryDelay`、「最近成功」改按它判断 |
| 3 | 助手并行任务在锁外改 `job.Warnings` | `QueueWorker.WithPrivateWarnings` 包住规划、提交、回退（8 处）；`Warn` 改到锁内；依赖解析提示先收集再合并 |
| 4 | 每次提交在主线程把助手文件哈希 6 遍 | `Post` 复用同一次 `PrepareWorkerTools` 的结果启动 |
| 5 | `mods.yml` 非原子写入；档案启停用 `yaml.Save` 整档重写 | 版本同步改走 `AtomicWrite`；新增 `ManagerProfileSync.SetEnabled`，只改 `enabled:` 行，`ModToggleService` 改为调用它 |
| 6 | 启动失败时叠出多个弹窗进程 | 命名互斥量 `Local\MCE.UpdateWorker.FatalDialog`，同一时刻最多一个弹窗 |
| 7 | 后台线程读 `Snapshot` 会触发 `Poll` | 新增锁内只读属性 `OverviewUpdateQueue.Network`，`ShopNetwork.Client` 改用它 |
| 8 | fake-ip（198.18/15）在直连时被拒 | 整组解析结果都是 fake-ip 时放行；掺有真实内网地址时照旧拒绝；`IsPublicAddress` 语义不变 |
| 9 | 新装停用时用旧后缀 | 改用 `PluginFileNames.DisabledSuffix`（`.d`） |
