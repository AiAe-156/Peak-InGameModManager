| 项目 | 本轮实现／边界 |
|---|---|
| 固定顶组 | 普通可编辑组之前固定展示，简中 `基础组件(Core/Patcher)`、繁中 `基礎組件(Core/Patcher)`、英文 `Core/Patcher`。类型分别 `核心组件(Core)`／`核心組件(Core)`／`Core`，`启动补丁(Patcher)`／`啟動補丁(Patcher)`／`Patcher`。不加入 OverviewMod、profile Mods、groupId 或导出目标，不伪造 GUID。 |

| 名称内反向树 | 展开的是“谁依赖此组件”，不是本组件依赖谁。小箭头逐层展开，名称列内缩进／竖线／分支、实际版本或未知、manifest／BepInDependency／assembly 证据及 hard/soft、cycle/shared/unknown/截断。UI 最多16层、24节点行预算，其他列顶行对齐；节点只读，无模组选择／拖拽／卸载交互。图 API 默认16层／256项，硬上限64层／4096项，不混称 UI 预算。 |
| 完整硬依赖永久禁卸载 | 唯一种子为实际 GUID `com.aiae.modconfigenhance`，按包级向前遍历硬 manifest、BepInDependency、assembly refs，跨 plugins/core/patchers；同包跨区域及资源合并保护，显示仍保留区域行。包括 MCE 自身及传递硬闭包，不只是固定几个库名；禁用 DLL 仍采 metadata，不因禁用或 owned 状态绕过。soft 不扩展硬闭包。这里“永久”指当前管理环境中的独立卸载入口不得解除保护，不表示跨包固定宿主或禁止完整环境切换。 |
| 保持更新 | 固定保护仅禁止卸载；版本入口、更新能力不因此变灰，仍须现有最终依赖／版本／写权限检查。⊘、名称／来源 tooltip、禁用卸载项及可点击“为什么不能卸载”保留完整原因链；普通模组来源菜单同样受保护。 |
| 未知安全 | 无真实MCE种子、无scope失败、MCE闭包采集失败或完全未解硬引用时全局fail closed；无关scoped坏DLL／manifest保留失败范围，不污染已知MCE链；未知owner仅允许进入核查，不授权删除。不用 UI 标志、旧图或 saved revision ledger 判定可删。 |
| 用户安全预览 | 非保护且证据完整才进入原流程。patcher 沿用 UninstallDialog；core 经 ShopWindow，等待真实安装快照、核对原包和实际现装版本，受完整环境／归属等原门禁约束；官方旧 ZIP 明确同意→下载批准→文件预览→用户确认，不自动 confirm、不直接删除。卸载保留既有配置策略。 |
| worker 三阶段兜底 | preview-uninstall 在 claim／下载前、approve-download／confirm-uninstall 确认边界、commit 写入前，重采当前实际文件及当前 workspace ledger。保留 ProtectedHost、CheckConsumers、CheckFinalPlugins、文件重验与既有 journal／rollback 流程。更新不走固定卸载门禁。 |
| 异步刷新 | 主线程捕获真实 SourceKey→AssemblyPaths/Location，后台一次采集，行渲染只读快照。inventory revision、generation、workspace+RevisionStateHash 拒绝过期结果；编辑／滚动／键盘选择期间延后重画，保留滚动恢复。Cecil 只读 metadata，不 Assembly.Load／执行第三方代码或解析第三方类型；不扫库存 revision。 |
