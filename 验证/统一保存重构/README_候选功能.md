# 统一保存候选：操作说明

本文件描述当前实施目标及已接入操作，不代表已部署。完整验收状态看当前验收清单.md。

## 保存

- 参数、快捷键和启停先进入草稿，修改项右上角橙色标记。
- 概览“保存配置”提交工作区修改及待安装/更新/卸载；涉及资源时显示清单和下载授权。
- “保存快捷键”“保存参数”“保存资料”“保存分组”“保存介绍”只提交对应内容。
- 保存后生效时机分立即、重新开局、重启游戏、启用模组后使用。未明确声明的显示“由模组决定”。
- 未加载模组cfg可以编辑并保存。无效/类型变化参数跳过，恢复草稿保留其未保存状态，其他有效项正常保存。
- 变更检查目录支持分类、搜索、按模组查看原值/新值和生效时机；正常保存不再弹“配置已应用”窗口。

## 配置与整合包

- 配置只含参数、快捷键、启停目标，导出`.mceconfig.json`，导入先进入当前草稿。
- 整合包包含模组文件、版本来源、作者资料、介绍、图片视频字体、分组与若干配置预设。
- 切换预设共用整合包资料；改预设不自动创建“个人副本”。首次保存可保存到当前预设或另存新配置。
- `*`表示偏离保留原版，保存后仍保留。工具页“恢复原版预设到草稿”可还原，保存后使用。
- 橙色只表示尚未保存，与`*`分工不同。

## 模组资源待办

- 安装、更新、卸载先加入待办；保存配置后提交。
- 工具页可撤销未保存待办、重试/跳过失败、取消剩余已保存操作。
- 资源执行串行，保留恢复日志和备份；已加载组件等待退出。
- 卸载依赖影响可查看精确清单后“忽略并卸载”；同意绑定清单，变化时重新检查。
- MCE及必需依赖链受保护；其他core组件只要有精确归属即可进入卸载，不要求先迁移完整整合包。
- 共享文件保留给其他所有者，不按目录猜删；卸载默认保留配置。

## 性能诊断

- MCE内置性能采样/首开分段计时/悬停计量/字体扫描诊断已移除；性能诊断交给FrameDoctor。
- 无递归FileSystemWatcher；固定metadata按需检查、主动写入失效和页面刷新保留。
- 交接见交给FrameDoctor_性能诊断摘要.md。
