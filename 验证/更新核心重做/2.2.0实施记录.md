# 2.2.0 更新核心重做 实施记录（2026-11-02）

## 起因
2.1.24 现装的真实队列（`BepInEx\MCE\queue.json`）里 7 个普通更新 + 2 个 Core 操作全部失败，没有一个是模组本身不能更新：4 个是 `ShopDependencyValidation.Read` 用 Cecil 读 `[BepInDependency(guid, DependencyFlags)]` 枚举参数时没配 AssemblyResolver；1 个是同目录汉化 DLL 让 GUID 集合全等校验失败；1 个是依赖判定靠目录名认不出中文目录下已装的 PEAKLib_Items；1 个是为做"旧版对账"去下载旧版本 zip 得到 404；2 个 Core 是 `VerifyCoreClaims` 要求本地 core 文件与官方旧版逐字节一致。另有写锁忙/准备中命令被拒绝、`queue.json` 706 KB 每 250ms 整体重写、`BepInEx\MCE` 4.8 GB 从不清理、前台窗口是 35 行 WinForms 文本框且不显示真实错误。用户决定直接重做（跳过热修）。

## 改了什么
### 新增（`Updater\`，平铺以便旧验证工程的 `Updater/*.cs` 包含）
- `InstallMetadata.cs`：Cecil 元数据读取，带解析目录（DLL 所在目录、`core`、`PEAK_Data\Managed`），任何异常只记警告。
- `InstallArchive.cs`：解压与路径规范化（`plugins|patchers|core|config` 原样，其余进 `plugins/`），短保护名单（BepInEx/doorstop/Assembly-CSharp/PEAK_Data/脚本/exe），安全遍历。
- `InstallInventory.cs`：按 `manifest.json` 的 name+version 扫描已装包，不看目录名；版本宽松解析。
- `InstallPlanner.cs`：以本地为基线生成 `Transaction`（`Installer="v3"`）：GUID 匹配沿用本地布局与停用后缀，同 GUID 旧副本归档，额外本地文件保留并提示，config 已存在跳过，`RequiresExit` = 要动已加载或 core/patchers 原件。
- `Installer.cs`：提交（参数备份→原件/旧副本移入备份→复制→校验→登记）、回退、校验；商店账本/整合包文件表/商店目录缓存登记一律尽力而为。装完即删 stage。
- `InstallDependencies.cs`：解析 Thunderstore 依赖串，缺失/版本不够 → 生成自动依赖任务（`AutoDependency`、`RequestedBy`）。
- `InstallStorage.cs`：完成超 7 天归档 `history.json`（上限 200）；孤儿 jobs/backups 两周后删；stage/zip/tmp 清理。
- `WorkerStatus.cs` / `WorkerLanguage.cs` / `WorkerWindow.cs`：状态模型、三语本地化（复用 `UpdateMessageCatalog`）、WPF 前台窗口（`#if NETFRAMEWORK`）。
### 改写
- `QueueWorker.cs`：`Execute` 走新管线（解析→下载→解压→规划→依赖门→等退出判定→提交）；`DependencyGate` 自动入队；`DeferredCommandException` 让锁忙/准备中/整合包切换中的命令留在 `commands/` 下轮重试而不是拒绝；`AddJob` 同目标去重、旧未完成任务接替；重试丢弃 prepared 事务；`LoadedAssemblyPaths` 收敛到快照级；进度写入 1s 节流；空闲 GC；`PublishStatus`/`HandleControl` 对接窗口（窗口按钮也写命令文件，和游戏侧同一入口）。
- `WorkerParallelOperations.cs`：`update-batch` 里的 `preview-install` 项转成队列任务（Core 组件走这条）；卸载/本地导入仍走 `ShopQueue`。
- `Program.cs`：`--language`、新窗口、交互模式 `FreeConsole`。
- `MCE.UpdateWorker.csproj`：`UseWPF`，补 `<Using Include="System.IO">`（UseWPF 会换掉隐式 using 集合）。
- 契约：`UpdateJob` 加 `Install/AutoDependency/RequestedBy/Warnings`，`UpdateSnapshot` 加 `LoadedAssemblyPaths`，`Transaction` 加 `Installer/RequiresExit/Retired/Extras`。
- 游戏侧：`OverviewUpdateQueue.EnsureWorker` 传 `--language`；删除无调用的 `HasRetriableForPackage`；队列行显示"N 条提示"，详情列出提示。
- 删除：`WorkerForegroundWindow.cs`。
### 保留但不再被普通更新调用
`PackagePlan.Prepare`、`Transactions.Commit/PlaceLive`、`UpdateLedger`、`ShopOwnership.ValidateUpdate*`、`ShopCoreBatch.VerifyCoreClaims`（交互式商店预览仍用）。旧 `Transaction` 事务（`Installer==""`）的回退与提交仍交给 `Transactions`。24 个旧验证工程直接编译这些文件，本轮不删，后续单独清理。
