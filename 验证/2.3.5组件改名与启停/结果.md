# 2.3.5 基础组件改译名与启停

接 2.3.4 识别那一步之后的第二步。改动前快照：`备份/2.3.5_20261109_组件改名启停前/`。

## 用户拍板
基础组件除 MCE 必需的 3 项外，都可以卸载、删除、改译名、启停。「改译名」指在概览里改显示名，不动磁盘。基础组件不能改分组，也不参与目录整理。

## 做了什么
| 项 | 改法 |
|---|---|
| 改译名 | 规则 ID `component:<Team-Name>`，复用模组的 `alias` 存储和 `SavePackInformation(ModInformation)`；列表行与详情标题显示为「译名（包名）」。详情窗新增「改译名」，保存失败会回滚 |
| 启停 | 新增 `ComponentToggle`：把组件的全部运行时文件在 `x.dll` 和 `x.dll.d` 之间改名，走 `InstallationWriteLease` 日志；改名前先整体预检，目标已存在、越出 BepInEx、文件缺失时一个都不改。MCE 必需依赖只能启用不能停用；外部工具停用的请用原工具恢复。详情窗新增「停用/启用」并带确认；最左列显示 ✓/○ |
| 状态筛选 | 「启用/停用」筛选改为按实际文件状态判断 |
| 分组、整理 | 复核代码：分组编辑器的候选只来自模组行，整理只采集 `plugins/`，组件进不去 |
