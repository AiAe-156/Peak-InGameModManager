# 诊断提示组交接（2026-10-29，固定2.0.0）

## 本组改动

- `src/Overview/DiagnosticSummary.cs`（新增）：共享结构化前端诊断。`ForPackage(graph,key)` / `FromCapability(capability)`；`Summary` 是三语短文，不含原始 Reason、errors、路径；`BlockReason` 只在后端 capability 不允许独立卸载时非空；`Details` 保留原始诊断、相关 scope 的 node/path/reason，交给 ShowText；`DetailsLabel` 明确“查看检查详情”。`EnvironmentRequired(details)` 和 `OwnershipRequired(details)` 分别表示实际完整环境未迁移、归属未核实，不能从英语 reason 字串猜状态。
- `src/Overview/SourceUi.cs`：component/普通 mod 菜单统一使用 helper；普通 mod 菜单有真正 disabled 卸载按钮和动态重验，商店/版本项不因 MCE 保护禁用。两种菜单都有“查看检查详情”，调用原有可滚动、有复制按钮的 `OverviewUi.ShowText`。`DependencyDiagnostic(key)` / `ShowDependencyDetails(key)` 可由其它前端复用。保留 context、inventory revision 检查及真正执行前重验。
- `src/Overview/InfrastructureDependencyCollector.cs`：captured confirmed SourceKey→AssemblyPaths 向上查最近 manifest 作为 hint 边界；标准 Thunderstore 无 namespace manifest 可从唯一且名称匹配的已确认身份补 namespace；父包 manifest 支持 bin/payload 映射。子包的 confirmed 身份不混入父包 hints。混放多包、显式身份矛盾继续拒绝；不再信任目录名相同就猜包。原始 JSON/IO/边界错误保留为 scoped failures，不吞错，不把错误铺到 tooltip；保留 captured Hash。

## 给布局组的共享接线（本组不改 OverviewListView/OverviewDependencyHints）

- 用 `DiagnosticSummary.FromCapability(capability).Summary` 或 `SourceUi.DependencyDiagnostic(key).Summary` 替换原 `.Reason` tooltip；tooltip 不要附 Path / Failures / errors，普通依赖提示中的长证据也不能直接拼接到普通 hover。
- 点击明确的 `DiagnosticSummary.DetailsLabel` 调用 `SourceUi.ShowDependencyDetails(key)`；或 `OverviewUi.ShowText(DiagnosticSummary.DetailsLabel, DiagnosticSummary.ForPackage(graph,key).Details)`。
- 不用 `Summary.Length > 0` 判断是否禁卸载：局部 scoped unknown 在 backend 允许 verification-only safe preview 时 `CanUninstall=true`。UI 保持原真正门禁，以 `CanUninstall` / `BlockReason` 为准，不放开 backend 拒绝；也不把全部 scoped unknown 禁掉。
- `CanUpdate` 独立于保护卸载，无全局更新 veto。完整环境/归属实际门禁是另一个结构化状态，不伪装为 MCE 依赖保护。
