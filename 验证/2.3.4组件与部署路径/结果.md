# 2.3.4 识别更全 + 部署路径修正 + 部署前检查

改动前快照：`备份/2.3.3_20261109_窗口与分组前/`（2.3.3 的整份）、各工程自己的 `备份/部署路径修正前_20261109/`（csproj）。识别规则见 [识别与接管规则.md](识别与接管规则.md)，盘点见 [识别盘点.md](识别盘点.md)。

## 用户拍板
- 只有 manifest、没有 DLL 的包：按「资源包」正常显示，既不算停用，也不算缺失。
- `.dll` 后面带任何字符：都认作已停用的副本。
- 散放 DLL、资源包、外部工具停用的模组：都可以接管，用提示代替拦截。
- 基础组件（core/patchers）：MCE 必需的 3 个依赖除外，允许卸载、删除、在概览里改译名、启停；不能改分组；不参与目录整理。
- 部署路径：改到现装位置，并加进工作流，每次部署前检查一次。
