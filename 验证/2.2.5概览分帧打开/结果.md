# 首次打开概览不再单帧卡顿（2.2.5）

承接 2.2.4 的「未做」第一条：`OverviewEntry.Update` 单次 441/381 ms。当时定性为「一次性 shell/入口预建」，**定性是错的**，本轮先取证再改。

## 取证（FrameDoctor 报告，2026-11-04 09:14 那次运行）

报告：`BepInEx\FrameDoctor-Logs\2026-11-04_09-14-20\framedoc_report.md`

| 时刻 | 帧 | 方法 | 单次 ms | 其中 self ms |
|---|---|---|---|---|
| 09:15:03 | 2819 | `Overview.OverviewEntry.Update()` | 381.2 | 369.9 |
| 09:15:03 | 2820 | `Overview.OverviewPage.Update()` | 140.0 | 140.0 |

同一帧（帧总时长 448.8ms）里的两条 MCE 日志把位置钉死了：

- `Transitioning to MCE_OverviewPage` —— 只可能由 `CompleteOpen()` 里的 `TransistionToPage` 打出；
- 本局第一条 `[概览名称]` 报的是 **400×48** —— 页头 `_packName`（`RefreshHeader` 里 `nameWidth = Min(400,…)`），而入口那个 `_name` 是 335 宽，且它在插件加载时就已设过文本、不会等到这一帧才首次播报。页头文本由 `BindRepository()` 创建 → **`BindRepository` 就在这一帧跑**。

`self = 369.9ms` 是「扣掉已插桩子调用」后的自身耗时。这份报告里被插桩的 MCE 迭代器只有 4 个（`AutomaticUpdateChecks+<Run>`、`ModSources+<Discover>`、`ThunderstoreUpdateService+<CheckAsync>`、列表的 `BuildModLayers`），**没有** `BuildShell`。

### 结论与更正

- **不是 shell 预建**：`BuildShell` 每步只建 1–3 个控件，`PumpShell` 每帧最多 8 步 / 4ms，全表 12 步，最多两帧就完 —— 它本来就是分帧的。
- 真正的元凶是它**后面**那段：外壳跑完的同一帧里，`Update` 的 `_opening` 分支直接 `CompleteOpen()` = `BindRepository()`（建 profile/update 工具、整个 `OverviewListView`、`OverviewHotkeyView`、悬浮提示、`RefreshHeader`）+ `TransistionToPage` → `OnPageEnter()`，全部没进预算。
- `BindRepository` 与 `OnPageEnter` 的内部占比，报告给不出（它们不是 Update/LateUpdate/MoveNext，FrameDoctor 看不见内部）。因此本轮**只改已被证实的那一段**：把绑定分帧；切页与 `OnPageEnter` 保持原样，等下一次实机日志再看剩下多少。

## 改了什么

| 位置 | 改动 |
|---|---|
| `src/Overview/OverviewController.cs`（`OverviewEntry`） | 新增 `_stage` 与 `StepOpen()`：建壳 / 绑定 / 切页三段各为独立一段，一段跑完下一帧才开下一段；`CompleteOpen()` 折成 `FinishOpen()`（只做切页）。`Update` 的 `_opening` 分支改走 `StepOpen()` |
| `src/Overview/OverviewController.cs`（`OverviewPage`） | `BindRepository()` 改为迭代器 `BindSteps()`，按建造顺序拆成 8 步、7 个让步点：仓库接线+工具入口+悬浮提示 / 页头文本 / 内容区与状态行 / 工具条 / 模组列表视图 / 快捷键视图与回调 / 四个悬浮提示 / `RefreshHeader`；`_bound=true` 仍在最后一步 |
| 同上 | 删除 `OverviewPage.Initialize(UIPage, OverviewRepository)` —— 无调用方的死代码，正是「建壳 + 绑定同步一次跑完」的那条路径 |

三段共用 `PumpShell` 原有预算（每帧最多 8 步、约 4 ms），未新增任何计时/采样钩子。页面在切页前一直是 `SetActive(false)`，未绑定期不会有组件跑 `Update`，所以行为与外观不变。

版本号 2.2.4 → 2.2.5，同步 7 处：`src/Plugin.cs`、`manifest.json`、`ModConfigEnhance.csproj`、`Desktop/MCE.Desktop.csproj`、`Updater/MCE.UpdateWorker.csproj`、`README.md`（标题与章节）、`CHANGELOG.md`。
