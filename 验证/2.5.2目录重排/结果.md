# 2.5.2 config\ModConfigEnhance 目录归成四大类

用户选「归成四个大类」并要求一次做完。

## 新布局
```
language/            语言文件
profiles/            配置方案、整合包介绍与素材（不动）
output/translation/  导出翻译、补漏翻（原 translation-export、export）
output/packs/        整合包导出、介绍导出（原 exports）
output/logs/         日志导出兜底（对话框不可用时）
data/runtime/        运行状态、商店缓存、收藏（原 runtime、log-favorites.json、shop-favorites.json）
data/backups/        全部自动备份（原 backups；原 backup 并进 data/backups/legacy-backup）
data/help/           使用说明本地覆盖（原 help）
data/legacy/         10 月前旧版概览数据与个人副本资源（原 overview）
readme.md
```
字体目录 `fonts/` 与 `pack-information.json` 只在作者模式下出现，位置不变。

## 改动
- `src/Updating/MceDirectories.cs`：唯一路径来源 + 搬家表 `Moves` + `Remap`；更新助手 csproj 链接同一份。
- 30 处写死路径改走它（脚本 `edit_paths.py`，每处断言只命中一次）；另修两处「没有激活整合包时从 runtime 往上找」：`PackLibrary.RuntimeRoot`、`PublishedPack.LanguageDirectories`；`OverviewProfileStore.RuntimeDirectory` 未托管时指向 `data/runtime`。
- `src/MceDirectoryMigration.cs`：`Plugin.Awake` 最前面执行。先复制状态文件（json/txt/md 等，单个 ≤16 MB）到 `BepInEx/MCE/backups/directory-layout-before-时间/`（不在被搬目录里），再同盘移动（目标存在就逐个并入，同名改名 `.old-layout`），改写 JSON 里的旧绝对路径；`data/.mce-layout-v2` 标记，失败下次接着做。
- 三个回归夹具（CacheChecks / ResourceDraftChecks / ConfigTransactionChecks）补链接 `MceDirectories.cs`，ResourceDraftChecks 的 Loc 桩补 `RuntimeDirectory`。
