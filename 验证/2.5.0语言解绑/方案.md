# 2.5.0 多语言自管、解绑 XUnity（方案，待用户确认）

## 现状（2026-11-11 核对）
- `manifest.json` 把 `RTLC-XUnity_AutoTranslator-5.6.11` 写成商店依赖，装管理器就强制装上它；代码里它是软依赖、全反射。
- 管理器自己的界面、概览、说明面板、侧栏模组名都走自己的词典（`Loc.TranslateExternal`）。
- **唯一靠 XUnity 的缺口**：ModConfig 原生设置页里其他模组的选项名、分区页签、下拉选项。现在是把语言文件里非 `MCE_` 的行写成镜像 `BepInEx/config/Translation/<码>/Text/ModConfigEnhance_<码>.txt`，再切 XUnity 语言、改它的 ini 让它去翻。
- XUnity 相关代码约 1500 行：`XUnityBridge*.cs`、`XUnityMachineTranslationGuard.cs`（约 16 个补丁拦它的机翻）、`Loc.SyncXUnity`/镜像/改 ini、工具行「显示原文 / 重载翻译」借它的 Alt+T / Alt+R、「补漏翻」没装就拦。
- 现场语言目录（`config/ModConfigEnhance/language/`）：`en-us.txt` `zh-cn.txt` `zh-tw.txt`（首次运行写出的 68 条界面词条快照，之后不再更新，内置词条现已 2178 条）+ `zh-cn_合并_20260918.txt`（1170 行）+ 两份 `zh-cn_补翻_<日期>.txt`。同组按文件名叠加。另有 `export/`（待翻文本、日志兜底）和 `exports/`（整合包导出）两个名字几乎一样的目录。

## 方案
### 1. 解绑
- manifest 去掉 XUnity 依赖；`[BepInDependency]` 保留软依赖（只为加载顺序）。
- 删除：镜像写入、切 XUnity 语言、改 `AutoTranslatorConfig.ini` 的 `Language=`、精确译文查询回退、16 个机翻拦截补丁。

### 2. 自己补上 ModConfig 设置页
- `MceConfigLabels.Refresh` 从「只翻本模组」扩到所有模组：选项名、分区页签、下拉选项都查当前语言文件（原文=译文），查不到显示原文。只改显示，不碰 cfg 里的键。
- 搜索已能匹配译文，不用改。

### 3. 工具行改成自己的
- 「显示原文 / 显示译文」：自己的开关，全部模组文字一键切回原文对照（界面词条不切）。
- 「重载翻译」：只重读自己的语言文件。
- 「补漏翻」：不再要求装 XUnity，按自己的语言文件判断哪些没翻。

### 4. XUnity 兼容与提醒
- 检测：XUnity 已加载，且它的 ini `[Service] Endpoint`（或 `FallbackServiceEndpoint`）不为空 → 判为「开着在线机翻」。
- 提醒（明确、不拦截）：每次启动第一次打开概览时弹一次说明窗：「检测到 XUnity AutoTranslator 开着在线机翻，它可能把模组文字发到网上翻译、和本管理器的译文打架」；按钮「关闭它的在线机翻」「知道了」「不再提醒」。另在设置页语言行旁常驻一个琥珀色提示角标，悬停有说明。
- 「关闭它的在线机翻」= 先备份再把 ini 的 `Endpoint=` 清空，下次启动生效。只在用户点了才改，不再默认去改它的文件。
- 只装了 XUnity、没开机翻：不提醒，两边互不干涉。

### 5. 语言文件夹结构（简化）
```
config/ModConfigEnhance/
  language/
    zh-cn.txt      一种语言一个文件：模组文字「原文=译文」；界面词条只在想改时写「MCE_键=文字」覆盖
    zh-tw.txt
    readme.txt
  translation-export/   导出的待翻文本（原 export/，与整合包的 exports/ 分开）
```
- 英文是原文，不再生成 `en-us.txt`。界面词条以内置为准，不再把快照写进用户文件（旧快照只会过时）。
- 补翻不再新建 `zh-cn_补翻_日期.txt`：导出 → 填好 → 点「导入补翻」，把填好的行合进 `zh-cn.txt`（同原文以导入的为准），并告诉你合进了几条。
- 概览里双击改译名直接写进同一个文件（原来写 `_personal.txt` 分层，是为了不改作者文件；作者语言文件本就在整合包目录里，用户目录只有自己的文件）。
- 整合包里的语言文件也是一种语言一个文件，读取顺序不变：个人 → 作者 → 内置 → 英文原文。
- 「语言码-变体」（如 `zh-cn-old`）保留：任何 `<名字>.txt` 都是一种可选语言，首行 `// display:` 是显示名。

### 6. 迁移现有文件（要你同意）
- 首次启动 2.5.0 时，把 `zh-cn.txt` + `zh-cn_合并_…` + 两份 `zh-cn_补翻_…` 按现在的叠加规则合成一个 `zh-cn.txt`（与现在看到的效果完全一致），`MCE_` 快照行里和内置相同的丢掉、改过的保留。
- 原文件整体移到 `language/_迁移前备份_<日期>/`（`_` 开头不会被当成语言读）。
- `export/` 改名 `translation-export/`；日志导出兜底位置跟着改。
- XUnity 目录里以前写的镜像 `Translation/en/Text/ModConfigEnhance_en.txt`（429 行）是本管理器生成的，迁移时移进备份。

### 7. 同步改的文档
三语 README / LanguageReadme、内置使用说明、介绍站 `language.html`、商店介绍初稿里的「XUnity 联动」改成「兼容 XUnity」。

## 逐项影响核对（2026-11-11，读源码 + 现场文件）

| 功能 | 现在怎么做 | 去掉 XUnity 后 |
|---|---|---|
| 导出翻译 | 从各模组 cfg 收集原文（`ModConfigTranslationExport.Collect`），写到 `export/` | 不受影响。只有文件头里「目标语言」一行取自 XUnity，改为取当前语言文件 |
| 补漏翻 | 装了 XUnity 才能用；问它的内存词典（含正则、替换），没装直接拦下 | 改为查自己的语言文件，**没装 XUnity 也能用**。失去的只有「认得 XUnity 的正则 / 替换规则」：现场这类规则 0 条（`_Substitutions` 等全是空文件，语言文件里无 `r:` 行） |
| 导入 / 加载语言文件 | 自己解析 `language/`、整合包 `language/`（`Loc.Scan/Parse`） | 不受影响 |
| 换语言实时刷新 | `Loc.Apply` → 刷本模组文字 + `TranslationRevision` 加一，侧栏、说明面板、概览按版本号重画；另外重写镜像并让 XUnity 重载 | 自己这条链不变；去掉的只是镜像和让 XUnity 重载 |
| 重载翻译按钮 | 重读自己的文件 + 让 XUnity 重读它的词典（Alt+R） | 只重读自己的文件。XUnity 自己的词典仍可在它那边按 Alt+R |
| 显示原文 / 译文 | 借 XUnity 的 Alt+T，切换全屏所有被它翻过的文字 | 改成自己的开关，只切本管理器负责显示的文字（侧栏、概览、说明面板、ModConfig 设置页），游戏本体和别的模组界面不跟着切 |
| 概览模组名 / 简介、侧栏模组名、说明面板 | 先查自己的语言文件，查不到再问 XUnity 精确词典 | 只查自己的。现场 XUnity 目录里除了本管理器写的镜像外没有任何词典，所以显示结果不变；装着 XUnity 的人，它照样会在屏幕上翻英文原文 |
| 整合包里的语言 | 随包的 `language/` 文件，打包时本就排除 `Translation/` 与 XUnity 配置 | 不受影响 |
| **ModConfig 设置页里其他模组的选项名、分区页签、下拉选项、选项说明** | **只能靠镜像让 XUnity 翻** | **会变回英文，必须自己补**（方案第 2 步）。这是唯一真正的缺口 |
| 写进语言文件、但不在本管理器界面上的文字（别的模组的 HUD、游戏里的提示） | 也通过镜像交给 XUnity 显示 | 不再生效。现场核对：语言文件 1103 条原文里，304 条不在导出文件中，其中 267 条仍是现有 cfg 里的选项文字（说明/选项名），其余 37 条是模组名和已卸载模组的旧说明，**没有一条是游戏画面上的文字**（脚本 `coverage.py`、`incfg.py`，清单 `outside.txt`、`outside_not_cfg.txt`） |
| 在线机翻拦截、游戏原生文字防覆盖 | 16 个补丁常驻拦截 | 去掉，改为检测到它开着在线机翻时明确提醒 + 一键关（方案第 4 步） |

### 实现时要注意
- ModConfig 设置页的下拉选项现在是原地改 `option.text`，只对本模组做所以没出问题；扩到所有模组后，切回英文必须能还原，要先记下原文再翻。
- 设置页文字要在这些时刻都重翻：打开页面、切模组 / 分区、翻页、搜索、筛选、换语言、重载翻译、显示原文开关。现有挂点（`ShowSettings`、`UpdateSectionTabs`、换语言回调）覆盖前五个，后三个走 `RefreshStaticTexts`，实机逐个看。

## 风险
- ModConfig 设置页单元格是 ModConfig 自己建的，文字可能被它后续刷新改回：沿用现有 `MceConfigLabels` 的挂点（ShowSettings 后、换语言后），实机要看翻页 / 搜索 / 筛选后是否还在。
- 同时装 XUnity 且它有自己的词典：它只翻英文原文，我们写上去的中文不会被它再翻；英中混排（如「v1.2 模组」）理论上可能被它机翻，所以开着机翻时才提醒。
